# Desafio em C#

Isso é de ago/2022 a nov/2022, da época da faculdade. Coloquei no GitHub em 2026 como registro e deixei como estava.

Lista de exercícios de lógica que resolvi em C#, como aplicação de console no Visual Studio. Cada questão ficou num arquivo: `questao1v.cs` a `questao3v.cs` são de vetores e `questao1m.cs`, `questao2m.cs` e `questaoMatriz.cs` são de matrizes. A da mediana, em `Program.cs`, ficou só com o enunciado.

## Como abrir

Abra o `Desafio.sln` no Visual Studio e rode com F5. Só um arquivo por vez pode ter o método `Main`; hoje é o `questao2m.cs`, e os outros eu renomeei pra `Main1`, `Main3` etc. Pra rodar outra questão é só trocar os nomes.
